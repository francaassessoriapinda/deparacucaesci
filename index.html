DE: PARA — IMPLANTAÇÃO SCI
DE: PARA — Implantação SCI. Localiza automaticamente a conta correspondente no SCI para cada conta do plano do Cuca Fresca, e sinaliza o que precisar de conferência manual.
Como usar: carregue o PDF do Plano de Contas do Cuca Fresca e a planilha de Listagem de Contas do SCI, e clique em "Localizar contas automaticamente". Revise as contas marcadas como a revisar (✔️ confirma a sugestão do SCI, ✏️ escolhe outra conta) e as não localizadas (✏️ vincula manualmente, ou ➕ marca que a conta precisa ser criada no SCI). No final, clique em "Exportar para Excel".

Atenção: como são muitas contas, é normal não dar para revisar tudo de uma vez — dá para fazer aos poucos. Mas este arquivo HTML não guarda as alterações dentro dele mesmo: cada vez que ele é reaberto, o trabalho começa do zero. Para continuar de onde parou, clique em "Salvar progresso (arquivo)" antes de fechar, e da próxima vez, depois de reprocessar os mesmos dois arquivos, clique em "Carregar progresso" para recuperar tudo o que já foi revisado.

Exportação: "Exportar para Excel" gera um relatório completo, fácil de ler. "Exportar no layout do SCI" mantém as colunas originais do SCI exatamente na mesma posição (nada é deslocado) e acrescenta o código e a descrição do Cuca Fresca correspondentes ao final de cada linha; quando mais de uma conta do Cuca aponta para a mesma conta do SCI, a linha é repetida uma vez para cada uma — para ser importado de volta no SCI sem alterar sua estrutura.

Modo recomendado — balancete do cliente: no primeiro campo envie o balancete analítico do cliente gerado no Cuca (PDF), no segundo a listagem de contas do SCI e no terceiro a planilha de participantes do SCI (opcional). A listagem do SCI traz vários planos empilhados: escolha o plano de destino (o recomendado é o plano padrão, com contas 01., 02., 03.…). A ferramenta lê só as contas com saldo, liga cada conta ao plano do SCI, aplica as regras de fornecedores/clientes/adiantamentos, encontra o participante (CNPJ) pelo nome e mostra no topo se os saldos fecham. Confira o que ficar em vermelho/amarelo (filtro Participantes pendentes, Não localizadas e A revisar) e clique em "Exportar saldos para o SCI". Para cada cliente novo, repita com o balancete dele.

Resolver milhares de contas de uma vez (fornecedores e clientes): clique em "⚡ Sugestão rápida" — todas as contas de fornecedores, duplicatas a receber e adiantamentos do Cuca são vinculadas a uma única conta do SCI (ex.: 02.1.1.01.001 Fornecedores, 01.1.2.01.001 Clientes) e marcadas como participante; no SCI, cada um entra pelo CNPJ. Para outros grupos (bancos, impostos etc.), use "📂 Tratar por grupo do Cuca": lista os grupos com a quantidade de contas pendentes e permite vincular o grupo inteiro a uma conta do SCI. A aba "Participantes" do Excel lista essas contas, com coluna para o CNPJ.

Fechando o que sobrar: use "✅ Confirmar sugestões a revisar" para aceitar de uma vez as sugestões acima de uma nota de confiança, e "➕ Marcar não localizadas para criar no SCI" para listar as contas que precisam ser criadas. Como o De-Para do SCI é único para todas as empresas, ele é feito uma vez só.

Atribuição em massa: digite um texto na busca (ex: "LTDA", um nome de fornecedor, um prefixo comum) e/ou escolha um filtro de bloco/status, para restringir a lista às contas que quer tratar juntas. Depois clique em "🗂️ Atribuir todas as visíveis a uma conta do SCI…" para vincular todas elas de uma vez só a uma única conta do SCI (útil, por exemplo, para jogar várias contas de fornecedores/clientes específicos numa conta genérica marcada como "conta participante" no SCI) — ou marcar todas como "criar no SCI" de uma vez.
